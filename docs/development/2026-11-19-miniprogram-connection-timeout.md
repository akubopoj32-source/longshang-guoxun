## 背景与结果

微信真机点击「连接服务」后仍显示加载。服务端日志确认手机的任务配置和记录列表请求均返回 200，电脑通过同一局域网地址读取两份 JSON 也正常。真机页面收到回调的情况仍需复测。

小程序按顺序读取任务配置和巡查列表，页面显示正在读取的内容。每次读取最多等待约 10 秒，超过时结束该次加载并显示出错步骤。收到正常的 JSON 文本或对象后更新页面，空记录库也可以进入巡查列表。

## 修改明细

| 文件 | 具体改动 | 原因与影响 |
|---|---|---|
| `miniprogram/utils/api.js` | 支持调用方指定读取超时，超时后结束等待并中止读取。兼容微信返回 JSON 文本或已解析对象 | 防止首页等待未触发的请求回调，并保留后端错误信息 |
| `miniprogram/pages/index/index.js`、`index.wxml` | 顺序加载配置和列表，校验响应结构，并显示当前步骤与超时提示 | 用户可判断问题出在哪一步，失败后可再次连接 |

## 接口和数据兼容性

沿用 `GET /api/config`、`GET /api/records` 和原有联调令牌，请求与响应字段兼容。首页连接读取使用单独的超时，巡查写入和录音转写沿用原超时。此改动只需重新编译小程序，桌面端和数据库无需更新。

## 合并与交接
