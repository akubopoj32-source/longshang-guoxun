## 双端接口和数据

- 小程序和电脑端连接同一个共享 Python 服务，按记录 ID 读取同一条巡查。服务可通过 `GET /api/config` 报告 `demo` 或 `model` 模式。
- 小程序用 `?view=mobile` 获取字段、照片数量和最新复核意见。电脑端用完整记录查看原图、原话和修订历史。调整 `record_response` 或新增字段时，应核对两种响应。
- 更新记录时，两端提交当前 `version` 和 `status`。若记录在另一端已更新，后端返回 `409`，调用方应刷新后再处理。
- 模型 URL、模型 ID 和 API Key 由后端环境变量提供。联调地址、令牌、模型密钥和 SQLite 数据存放在各自本机。部署步骤见[项目运行说明](../../README.md#微信小程序联调)。

## 合并与交接

小程序分支开始新开发前可将最新版 `main` 合入本分支，取得本次规范和模板。电脑端与小程序端分别提交功能及对应记录。遇到双方都依赖的后端改动，在合并请求里写出接口版本和依赖的提交，按记录里的顺序合并并复测。

双端复测时，新建一条模拟巡查，提交文字与示意图，按追问补充时间并更正点位。桌面端检查原图、字段和历史后填写退回意见，再回小程序刷新确认同一记录的状态及意见。接入模型的环境额外确认处理结果含照片线索。
